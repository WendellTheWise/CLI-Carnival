This is a carnival with games you can run in your Command Line Interface. The Game Library Includes:

Rock Paper Scissors,

Number Guess,

A Roulette Chance Wheel,

Hangman Word Guessing,

A Mastermind Code Cracker,

Anagrams To Solve,

War Card Game

Run The Command below the title in your terminal "pip install CLI-Carnival==0.1.4" and it will download. Navigate to it in terminal (you may have to unzip or download the file manually) Then run "carnival" in the root of your computer (assuming you have python installed, check with python --version)

This works in ubuntu linux, will not function in windows or mac. May work in WSL, untested.
