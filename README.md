This is a carnival with games you can run in your Command Line Interface.

To Download, Go To https://github.com/WendellTheWise/CLI-Carnival, click code and download as a ZIP. Unzip that file

In linux, navigate to the unzipped file in your command line, then run python3 main.py 
(Assuming you have downloaded python, if not, run sudo apt update, then sudo apt install python3)

I do not know how to run this in Windows or Mac, however the process for linux is the same in WSL and probably similar in Mac. Base Windows is unknown due to having a werid CLI system compared to Linux, mac and WSL.
