This is a carnival with games you can run in your Command Line Interface. The Game Library Includes:

Rock Paper Scissors,

Number Guess,

A Roulette Chance Wheel,

Hangman Word Guessing,

A Mastermind Code Cracker,

Anagrams To Solve,

War Card Game,

Simon Says,

Go Fish,

Typing Test,

Higher or Lower,

JellyBean Estimator,

Dice

Download the .deb And Double Click Where You Downloaded it. This Will Open The App Center, Download The App. Then Run "sudo apt install ./carnival_1.0.6_all.deb". Then Enter The Command "carnival" And The App Will Run.
This works in ubuntu linux, will not function in windows or mac. May work in WSL, untested.
